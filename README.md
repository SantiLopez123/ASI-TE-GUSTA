# ASÍ TE GUSTA · versión web

Prototipo académico (Idear Empresarial · Reto 3): CRM con reconocimiento facial para restaurantes.
Versión de demostración publicada en Streamlit Community Cloud. La cámara es la del navegador de quien
la usa; solo se guarda una huella numérica del rostro (nunca la foto) y los datos se reinician cuando el
servidor se reinicia.

Archivo principal: `app.py` · Python 3.11.
